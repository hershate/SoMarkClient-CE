# SoMarkClient CE 0.1.0

首个 Windows x64 桌面版本，采用 Tauri、React 和 Rust。

## 功能

- 提供文档解析、PDF 转 Word/PPT、HTML/TXT 导出。
- 支持本地文件、文件夹、公开/预签名 URL 和剪贴板图片。
- 提供中英文、深浅主题、简单/高级参数、内置及自定义预设。
- 支持多服务配置、Base URL、代理、额度查询和低额度策略。
- 安装版使用 Windows 凭据管理器，便携版不持久保存 API Key。
- 提供真实上传进度、云端阶段、任务筛选、历史记录和结果输出管理。
- 支持 Markdown/JSON 预览、目录导航、原文对照和 bbox 高亮。
- 支持 Markdown 编辑另存、静态 HTML 导出和结构化纯文本导出。
- 使用 SQLite 持久化队列，支持断网恢复、重启恢复、停止等待和部分成功重试。
- 提供托盘、桌面通知、提示音、脱敏日志和诊断包导出。
- 不收集使用遥测，不通过自建服务器中转用户文档。
