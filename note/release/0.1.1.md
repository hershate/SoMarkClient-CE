# SoMarkClient CE 0.1.1

本版本修复真实 Key 验证与解析响应兼容问题。

## 修复

- 保存和读取 API Key 时清除 BOM、零宽字符、首尾空白及成对引号，旧凭据无需删除。
- 保存服务配置后同步切换当前服务，避免任务和用量查询使用不同配置。
- 兼容 `message`、`warnings`、用量字段和 `outputs` 为 `null` 的响应。
- 错误消息支持 `message` 与 `msg` 两种字段，错误响应中的空字符串 `data` 不再按对象解析。
- 响应结构不匹配时显示期望类型及字段结构，便于定位实际 API 差异，不记录 Key 或文档正文。

## 验证

- 前端 TypeScript 与 Vite 生产构建通过。
- Rust `cargo check` 通过。
- 官方无效 Key 响应结构已验证：`code=1107`、`data=""`。
- 真实有效 Key 的用量查询和文档解析需用户使用本补丁版本再次验收。
