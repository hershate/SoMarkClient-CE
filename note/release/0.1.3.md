# SoMarkClient CE 0.1.3

本版本将默认 SoMark 服务地址统一为 `.cn`，减少 Key 与 API 域名不匹配造成的认证失败。

## 改动

- 首次启动创建的默认服务使用 `https://somark.cn/api/v1`。
- 新建服务配置的默认 Base URL 同步改为 `.cn`。
- 仍保留自定义 Base URL，可手动配置其他平台、私有化部署或兼容中转。
- 保留 0.1.2 的 JSON+ZIP 输出兼容与 Markdown 恢复逻辑。

## 分发产物

- `release/SoMarkClient CE_0.1.3_x64-setup.exe`：NSIS 当前用户安装包。
- `release/SoMarkClient-CE-0.1.3-portable.zip`：免安装便携版。

## 验证

- 默认服务地址已检查，应用内不再默认使用 `.ai`。
- 前端生产构建、Rust `cargo check`、Release/NSIS 构建通过。
