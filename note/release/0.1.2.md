# SoMarkClient CE 0.1.2

本版本修复 `.cn` 服务在上传文档后返回“无效的输出格式”的问题。

## 修复

- 根据服务端实际约束调整输出请求：ZIP 不再与 Markdown 同时请求，统一使用 `json + zip`。
- 下载并解压 ZIP 后恢复 Markdown，用户选择 Markdown/JSON/ZIP 时仍得到全部三种文件。
- 恢复后的 Markdown 同步用于结果预览、编辑另存和 HTML/TXT 导出。
- 保留 `.cn` 与 `.ai` 服务地址按 Key 来源配置的兼容性。

## 分发产物

- `release/SoMarkClient CE_0.1.2_x64-setup.exe`：NSIS 当前用户安装包。
- `release/SoMarkClient-CE-0.1.2-portable.zip`：免安装便携版。

## 验证

- `.cn` 实际响应确认：ZIP 不能与 Markdown 组合，只能单独使用或与 JSON 组合。
- 模拟服务验证请求中仅包含 `output_formats=json,zip`。
- 完整任务验证状态为 `success`，实际生成 Markdown、JSON、ZIP 和本地图片资源。
- 前端生产构建、Rust `cargo check`、Release/NSIS 构建通过。
